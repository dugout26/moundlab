## 측정 방법
- 클로드 코드에서 Opus 5.5와 Fable 5.2에게 똑같이 우주 슈팅 게임을 요청
- 그다음 **"더 재밌게 만들어 줘."**만 세 번 (총 4단계)
- 각 단계 결과를 브라우저 자동 플레이로 녹화, 소리는 게임 코드가 직접 만든 소리를 그대로 녹음
- 비용: API 요금 기준, 환율 1,470원

## 결과 (4단계 합계)

| | Opus 5.5 | Fable 5.2 |
|---|---|---|
| 비용 | 약 3,400원 | 약 11,200원 |
| 시간 | 8분 | 18분 |
| 답장 언어 (한국어로 요청) | 4번 다 영어 | 한국어 |
| 소리 | 효과음만 | 효과음 + 배경 음악 |
| 에러 | 0번 | 0번 |

단계마다 붙은 기능
- **Fable 5.2:** 피버 게이지, 스치기 보너스, 대시, 무기 세 종류
- **Opus 5.5:** 콤보, 폭탄, 업그레이드 카드, 기체 선택 (화면은 더 단순)

## 항목별 승부

| 항목 | 승 |
|---|---|
| 가격 | Opus 5.5 |
| 속도 | Opus 5.5 |
| 화면 연출 | Fable 5.2 |
| 소리 | Fable 5.2 |
| 한국어 답장 | Fable 5.2 |
| 에러 | 무승부 |

**3 : 2로 Fable 5.2.** 다만 7,800원 더 낼 가치가 있는지는 용도에 따라 달라요.
